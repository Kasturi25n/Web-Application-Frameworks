### Assignment 2: Bookstore & College Event
- **Bookstore**: Interactive bookstore web application with book catalog, shopping cart, and pricing.
- **College Event**: Event registration portal featuring technical and cultural event showcases.

### Assignment 4: ReactJS Lab Programs
A Vite + React 19 application hosting 10 modular lab exercises:
1. **Welcome Message & Student Info** (Functional Components + JSX)
2. **Student Info via Props** (Component Reusability)
3. **Counter** (`useState` hook)
4. **Student Form** (Controlled inputs & Event Handling)
5. **Digital Clock** (`useEffect` hook & Timer cleanup)
6. **Fetch Users** (API fetching with loading and error states)
7. **Theme Switcher** (Context API without prop drilling)
8. **Shopping Cart** (Lifting state, `useState` & props)
9. **Student Attendance Manager** (`useReducer` + Context API)
10. **Task Manager** (`useState`, `useEffect`, and Context API)
