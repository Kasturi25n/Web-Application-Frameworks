Home | Model | View | Controller

Definition

The Controller acts as a bridge between the Model and the View. It receives user requests, processes them, communicates with the Model, and sends the results to the View.

Responsibilities

  • Receive user requests
  • Process input
  • Communicate with Model
  • Send data to View
  • Control application flow

Workflow

  1. User enters login details.
  2. Controller receives the request.
  3. Controller sends request to Model.
  4. Model verifies the data.
  5. Model returns the result.
  6. Controller sends data to View.
  7. View displays the result to the user.
