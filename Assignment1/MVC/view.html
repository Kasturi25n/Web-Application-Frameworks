Definition

The View is responsible for displaying information to the user. It receives data from the Controller and presents it in a readable format.

Responsibilities

  • Display data
  • Show forms
  • Display tables
  • Display reports
  • Improve user interaction

Examples of User Interface Elements

  • Buttons
  • Text Boxes
  • Forms
  • Tables
  • Images
  • Navigation Menu
